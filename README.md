# Sovereign AI Transformation for Exploration & Production (E&P)
### Executive Strategic Pitch Deck for Oil and Natural Gas Corporation (ONGC)

> **Context & Objective:**  
> This interactive executive deck is prepared specifically for the **ONGC Executive Leadership & Board Meeting on Artificial Intelligence in Exploration & Production (AI in E&P)**. It presents Google Cloud's strategic blueprint for deploying autonomous, deterministic enterprise AI agents across ONGC's upstream lifecycle—safeguarding capital efficiency, operational integrity, and institutional subsurface expertise.

## Navigation & Presentation Controls

* **Next Slide:** `ArrowRight` or `Space`
* **Previous Slide:** `ArrowLeft`
* **Fullscreen Mode:** Press `F`
* **Theme Switching:** Persistent Light/Dark toggle in the top executive header
* **Dock Navigation:** Fixed floating pill at the bottom of each surface for one-click jumping between adjacent slides

## Technical Architecture & Security

* **Pure Web Technologies:** Built with semantic HTML5, modern vanilla CSS (utilizing CSS custom properties for theming), and GSAP for performance animations.
* **Zero Build Overhead:** Runs directly in any modern browser without npm dependencies or bundler steps.
* **Confidentiality Guardrails:** Integrated pre-commit security filter (`.githooks/pre-commit`) to safeguard proprietary customer materials and credentials.
